- 2026-10-30 — Function words (de, van, of, la, der, et, …; French, Dutch, English, German, Latin) are optional in a search: the hits with every word come first, in their usual order, then the hits that miss only function words; an author search and a quoted query keep every word — Pagefind requires all words, so "guibert de gembloux" missed "Guibert of Gembloux" (Jeroen Deploige, 26 Oct); this imitates the optional common terms of Lucene-style engines without a server, and no hit that was found before is lost or moved.
